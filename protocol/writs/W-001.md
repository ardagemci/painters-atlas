# W-001 — Integrity drift report

## What this writ is for

This is the first writ deliberately, and it is deliberately toothless. It can
read everything and change nothing outside `protocol/runs/`. Its purpose is to
prove the machinery — scheduling, isolation, the sealed-set hook, the two-tier
review, the ledger — on work where a total failure costs a wasted run and
nothing else.

It is also genuinely useful. Lane II work happens directly and often; this writ
is what notices when a hand edit quietly broke a reference, dropped an artist,
or desynchronised the agent roster from its definitions. Today nothing notices
that until someone happens to run the validator.

## What a run does

1. Run both `verifier` commands and capture their full output.
2. Read the previous run's recorded counts from `protocol/runs/ledger.jsonl`.
3. Compare. The registry counts printed by `validate.jxa.js` — artists,
   movements, techniques, eras, nations, painter styles, influence edges,
   venues, catalog, daily pool, museum notes, photo credits, artwork image
   credits, personas, lists, tier1 artists — are the drift signal.
4. Write `protocol/runs/YYYY-MM-DD-W-001-<short-sha>.md` containing: the commit
   range since the last run, both command outputs verbatim, every count that
   changed with its delta, and a plain statement of whether anything is broken.
5. Append one line to `protocol/runs/ledger.jsonl`.
6. Push the branch. Stop.

## What counts as a finding

- **Broken.** Either verifier exits non-zero. Report it at the top of the file,
  name the failing check, and stop — do not investigate the product further.
- **Drift.** A count moved without a commit that explains it. Report the count,
  the delta, and the commits in range. Do not guess at a cause.
- **Clean.** Both verifiers pass and every delta is attributable. Say so in one
  line. A clean report is a successful run, not a wasted one.

## What a run must not do

- Fix anything. A broken reference is a finding, not a task. The fix is Lane II
  work, by a person who can judge whether the reference or the referent is
  wrong.
- Interpret a count change as good or bad. Twelve artists added is drift worth
  reporting either way; whether it was intended is not a machine's call.
- Touch the pinned-image list in `tools/audit_artworks.py`, or any other file
  in the sealed set. Findings about the verifier go in the report.

## Successor

`W-002` is where this stops being observation: the first writ permitted to
*propose* a fix, on a branch, for the narrow class of breakage W-001 has proven
it can detect reliably. Do not write it until W-001 has run clean and unattended
for the Phase 4 period.
