# W-004 — Point every image at the page that licenses it

## The finding this repairs

W-003 resolved all 282 public-domain catalog images against Commons and found
**257 whose `image.page` points at an `en.wikipedia.org` article**. A Wikipedia
article carries no licence statement whatsoever. The images are fine — every one
resolves, every one carries a licence Commons asserts — but the provenance trail
Pigment ships does not demonstrate that. `PIGMENT.md` §14 makes the rights basis
a legal constraint, and owner decision OD-5 requires that basis be recorded
rather than assumed.

This is the first writ permitted to change a production file. It gets that
permission for one reason: **an external authority decides what the right answer
is.** The correct value for each record is not a judgement, a preference, or a
guess — it is the Commons file page that the record's own `image.src` resolves
to. Nothing here requires taste, and nothing requires knowing anything about the
painting.

## The work

1. Run `python3 tools/check_image_pages.py --list` for the current offenders.
2. Resolve each one's `image.src` to its Commons file page with
   `tools/rights_register.py`, the same tool and the same transient-failure
   rules W-003 used. **`tools/audit_artworks.py` is forbidden** — it has no
   read-only mode and rewrites `js/artworks.js` in place.
3. Replace **only** the `page:` value inside that record's `image:` block.
4. Write `protocol/runs/YYYY-MM-DD-W-004-<sha>.md`: how many changed, the
   before and after for a sample, and every record that could not be resolved.
5. Stop. The runner commits; the owner merges, or does not.

## Change one field and nothing else

`docs/BACKLOG.md` A2 is this repository's record of what happens when artwork
data is edited at scale without looking: twenty wrong pictures, and five that
silently kept the *previous* work's date after a retitle. Its own method note is
binding here —

> regex surgery on `artworks.js` produced malformed JSON twice; the file
> round-trips exactly through `json.dumps(indent=1)`, so structural edits should
> parse, modify and re-serialise rather than pattern-match.

Catalog files are hand-formatted JavaScript rather than JSON, so they do not
round-trip that way. Edit the `page:` string in place, one record at a time.
Do not reformat, do not reorder keys, do not touch whitespace on lines you are
not changing. A diff where every line moved is a diff nobody can review, and
review is the only thing standing between this and A2 happening again.

## A resolution that fails is reported, never guessed

If a record's image cannot be resolved to a Commons file page, **leave the
record exactly as it is** and list it in the report. Do not substitute a
plausible page, do not fall back to a search result, and do not construct a URL
from the filename. Five records in A2 carry their caveats permanently because
someone filled a gap with something that looked right.

A partial migration is an acceptable outcome and an honest one. The verifier
will fail while any record still cites a non-Commons page, so a partial run
parks its branch rather than reporting success — which is correct: a half-
migrated catalog with a passing report would be worse than no run at all.

## Why the verifier can be trusted

`tools/check_image_pages.py --require-commons` exits non-zero today, with 257
outstanding. It passes only when every public-domain record cites a Commons file
page. It cross-checks its own parse against W-003's register, which was built by
evaluating the JavaScript rather than parsing it, so a silent undercount by
either method disagrees with the other.

That check was written before this writ and has its own tests, including one
that fails if it is ever reduced to always passing.

## Successor

None planned. If this lands cleanly, the next question is whether the same
pattern — an external authority deciding a field's correct value — applies to
artist birth and death years against Wikidata. That needs its own checker built
first, in Lane II. Do not write W-005 before that exists; a writ whose
correctness nothing can test is not a writ.
