# W-003 — Artwork image and rights audit

## What this writ is for

W-001 looks inward: it asks whether Pigment's data is self-consistent. It always
is, because nothing outside the repository can make it otherwise. This writ looks
*outward*, at the one part of Pigment that can rot without anyone touching it.

350 catalog artworks point at files on Wikimedia Commons. Those files get
renamed, replaced, deleted, and re-licensed by people with no idea Pigment
exists. `docs/BACKLOG.md` A2 records twenty artworks that shipped with the wrong
picture and had to be hand-corrected — and nothing currently notices when a
*working* image silently becomes the wrong one, or when a public-domain file is
replaced by one requiring attribution.

That is a legal exposure (`PIGMENT.md` §14) and a truth problem about real
historical works, and it is exactly the shape of work a machine should do: too
tedious to do by hand, and decided by an external authority rather than by
taste.

## Use the existing tools. Do not write new ones.

`tools/rights_register.py` already does the resolution, and
`tools/commons_rights.py` already implements the rule that makes it safe:

> **A transient failure is never a negative finding.** upload.wikimedia.org and
> the Commons API both rate-limit hard, and this project has been burned.

Honour that rule. `PIGMENT.md` §14 states it as a constraint: *do not classify a
URL as dead because of a timeout, 429, or transient server error.* A run that
reports 200 dead images because Commons throttled it has produced a lie that
takes a person a day to disprove.

```sh
python3 tools/rights_register.py --surface catalog \
    --out-json protocol/runs/<date>-W-003-<sha>.json \
    --out-md   protocol/runs/<date>-W-003-<sha>.md
```

**`tools/audit_artworks.py` is forbidden.** It has no read-only mode and rewrites
`js/artworks.js` in place. Invoking it is an `abort_if` condition, not a
judgement call.

## What counts as a finding

Rank by consequence, not by count:

1. **Unresolvable file** — the Commons file behind a shipped image no longer
   resolves, *and* the failure is not transient. A blank artwork on a live page.
2. **Licence changed** — a record shipped as public domain whose file now
   asserts something else. This is the legal one; report it first.
3. **Attribution now required** — the file is still usable but the credit is
   missing. Cross-check `js/photo-credits.js`.
4. **Declared page is not a Commons file page** —
   `declared_page_is_commons_file_page: false`. The record's `image.page` points
   at a Wikipedia article, which carries no licence statement whatsoever, so the
   rights basis is unverifiable from what Pigment ships.
5. **Nothing changed** — say so in one line, with the number checked.

## What a run must not do

- **Repair anything.** Every finding here touches either a legal claim or a fact
  about a real artwork. Both are Lane II work, by a person who can look at the
  picture. A2 is the record of what happens when artwork identity is decided
  without looking.
- **Reach a legal conclusion.** Per owner decision OD-5, Commons's assertion is
  an *asserted* basis, not a rights determination. Record what Commons says.
  Do not write "cleared", "safe", or "we may use this".
- **Fill a gap with a guess.** A file that cannot be resolved is reported as
  unresolved. It is never quietly replaced with a plausible substitute — that is
  precisely how five records in A2 came to carry the previous work's date.

## Comparing against the last run

Unlike W-001, this writ's findings do **not** become a baseline automatically.
The runner records registry counts in the ledger; rights findings live in the
report, on the branch. To compare against a previous audit, that branch has to
be merged first.

That is deliberate. A rights report should be read by a person before it becomes
the thing the next run trusts. An audit that silently baselines its own
unreviewed output would launder a bad run into the record.

## Successor

`W-004`, unwritten, is the first writ permitted to *act* on a finding — and only
on the unambiguous class, where Commons returning 404 for a file means the image
is gone and the honest state is no image. Do not write it until W-003 has run
several times and a person has agreed with what it found. Nothing here has
earned the right to edit an artwork record yet.
